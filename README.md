## Быстрый запуск

Python 3.10+ (проверено на 3.12), XeLaTeX для презентации.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[lab]'
python -m pytest -q
python scripts/run_experiments.py
python scripts/build_notebook.py
cd slides
xelatex -no-pdf -interaction=nonstopmode -halt-on-error presentation.tex
xelatex -no-pdf -interaction=nonstopmode -halt-on-error presentation.tex
xdvipdfmx -o presentation.pdf presentation.xdv
```

Для Windows активация: `.venv\Scripts\activate`. В TeX Live нужны beamer, fontspec, polyglossia, amsmath, booktabs; шрифт DejaVu Sans. PDF можно открыть без установки TeX. `make all` выполняет проверки, расчёты, ноутбук и сборку слайдов. Выполненный ноутбук и результаты уже включены.

Обновление HTTP-данных: `python scripts/fetch_data.py`. Обычный запуск работает по приложенным копиям, не требует сети. `data/provenance.json` содержит URL, время получения, ссылки на первичные публикации и SHA-256. `environment-tested.txt` фиксирует фактически проверенные версии; `pyproject.toml` задаёт совместимые диапазоны.

## Физические эксперименты

1. **Символьная модель:** поля E(x,y,z,t), H(x,y,z,t), уравнения Максвелла; словарь `srepr`, граф выражения и направленная матрица смежности. Операторы grad, curl, div, dot, cross, Jacobian и векторный Laplacian.
2. **Сфера в вакууме:** точная частотная модель Ми против Рэлея; реальные опубликованные дисперсионные модели кварцевого стекла и воды. Сферический расчёт не является воспроизведением RFID-антенны.
3. **Maxwell 3D+time:** периодическая начальная задача на 24³ узлах со сглаженным диэлектрическим включением; 3D векторы и 2D срезы, энергия, div D, div H. Разность с однородной задачей — возмущение IVP, не far-field scattering cross section. Проверка сходимости на точной плоской волне.
4. **Reader/tag:** воздушные круговые катушки, интеграл Неймана, связанные RLC при 13.56 MHz. Восстановление M,R₂ по зашумлённому синтетическому току; отложенные точки, seed=20261029.
5. **Смешанная модель:** геометрия + пользовательская поправка ΔM + физический ODE. Интерфейс подготовлен, обученная нейросеть не заявляется.

## Статус данных и ограничения

Два независимых первичных исследования материалов представлены HTTP-файлами одного открытого репозитория RefractiveIndex.INFO. Это опубликованные аппроксимации дисперсии, а не два архива измеренных электромагнитных полей. Источники открытых данных не заменяют экспериментальную валидацию реальной RFID-системы. RFID-статья предоставляет измерения по запросу автору. Для её эквивалентной схемы создан учебный LF/HF-аналог: геометрия и частота не повторяют UHF-устройство статьи. Оптические n(λ) не используются для радиочастотных катушек.

Периодические границы означают периодическое продолжение среды; нет PML и условия Зоммерфельда. Пространственная дискретизация O(h²), временная RK4. Сглаживание сферы — осознанный выбор для грубой учебной сетки. Количественная ошибка неоднородного поля относительно независимого эталона не оценена; проверены ограничения и аналитическая однородная задача.

Приложенный PDF требует «найти данные из нескольких источников». Если преподаватель трактует это как **несколько экспериментальных 3D+time полей**, необходимы дополнительные данные. Текущая работа честно обозначает этот пункт как частично покрытый.
