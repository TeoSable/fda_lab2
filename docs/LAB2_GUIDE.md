# Лабораторная №2: запуск и структура

## JupyterLab в Windows

Откройте PowerShell в корневой папке проекта и запустите:

```powershell
.\.venv\Scripts\python.exe -m jupyterlab
```

В браузере откройте `notebooks/lab2_interventions.ipynb`. В меню
**Kernel → Change Kernel** выберите **Python (EMLab — lab2)**.
Первая ячейка выводит путь к Python и проверяет использование `.venv`.
Перед импортом визуализаций кэш Matplotlib направляется в
`tmp/matplotlib` внутри проекта.
Для выполнения выберите **Kernel → Restart Kernel and Run All Cells**.

Активация окружения не требуется: команда явно выбирает его интерпретатор.
JupyterLab и отдельное ядро уже установлены. Если ядро понадобится
зарегистрировать повторно:

```powershell
.\.venv\Scripts\python.exe scripts/setup_lab2.py
```

Установка на другом компьютере:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[lab]'
.\.venv\Scripts\python.exe scripts/setup_lab2.py
.\.venv\Scripts\python.exe -m jupyterlab
```

## Выполнение без браузера

```powershell
.\.venv\Scripts\python.exe scripts/execute_lab2.py
```

Для повторного построения таблиц и рисунков по сохранённым
бутстреп-выборкам:

```powershell
.\.venv\Scripts\python.exe scripts/execute_lab2.py --reuse-bootstrap
```

При чтении сохранённых результатов проверяются конфигурация,
массивы данных, код численных методов и версии NumPy/SciPy.
При несовпадении нужно выполнить обычный полный пересчёт.

Генератор восстанавливает структуру ноутбука из текста и коротких
вызовов функций; при этом сохранённые выходы ячеек очищаются:

```powershell
.\.venv\Scripts\python.exe scripts/build_lab2.py
.\.venv\Scripts\python.exe scripts/execute_lab2.py
```

## Модули и настройки

| Файл | Назначение |
|---|---|
| `src/emlab/lab2_config.py` | Физические константы, оптимизатор, настройки эксперимента |
| `src/emlab/intervention.py` | Решение RLC-системы, подгонка, бутстреп, шум, W1 |
| `src/emlab/lab2_data.py` | Подготовка данных и моделей |
| `src/emlab/lab2_experiment.py` | Запуск эксперимента, сохранение, правило удаления |
| `src/emlab/lab2_plots.py` | Все графики; оформление задаёт `PlotConfig` в начале файла |
| `src/emlab/lab2_reporting.py` | Таблицы и проверка окружения |
| `scripts/setup_lab2.py` | Регистрация ядра внутри `.venv` |
| `scripts/execute_lab2.py` | Исполнение ноутбука с сохранением выходов |

`DEFAULT_CONFIG` задаёт 300 бутстреп-повторов, пять реализаций
интервенции, уровни шума 0, 0.5, 1, 2, 4 и обе функции ошибки.
В конфигурации также находятся сетки, квантили интервалов и допуски
решения. Смена настроек требует повторного расчёта.

## Параметры моделей

В основной модели оцениваются взаимная индуктивность M в нГн
и сопротивление R₂ в Ом по току второго контура. Собственные
индуктивности, R₁, частота возбуждения и ёмкости заданы заранее.

В оптических моделях оцениваются амплитуды aⱼ формулы Зельмейера
при фиксированных резонансах. Данные получены из опубликованных
формул воды и стекла с добавлением заданной ошибки измерения.

Пример `silica_offset` использует те же данные стекла и добавляет
к модели свободный постоянный член c₀. Его истинное значение
равно нулю. Для него выполняются полный бутстреп, интервенции,
расчёт W1 и проверка удаления по общему правилу.

Правило сравнивает RMSE полной и сокращённой моделей после
повторной подгонки оставшихся коэффициентов. Допуск для тока равен
5% максимальной чистой амплитуды, для оптики — 2e-4 в n²−1.
Дополнительно проверяется частота попадания оценок на границы.

## Результаты и проверки

`results/lab2/bootstrap_draws.npz` содержит выборки коэффициентов;
`distances.json` — оценки, интервалы и W1;
`decisions.json` — ошибки прогнозов и решения по каждому слагаемому;
`summary.json` — настройки и происхождение данных;
`cache_manifest.json` — контрольную подпись для повторного использования.
PNG-графики и GraphML-графы сохраняются в той же папке.

Проверки:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check
.\.venv\Scripts\python.exe -m ruff format --check
```

Проверка оформления настроена для кода второй лабораторной
и её ноутбука. Версии окружения записаны в `environment-lab2.txt`.
